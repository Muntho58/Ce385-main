ข้อมูลนักศึกษา:เป็น array ของ object แต่ละ object คือข้อมูลนักศึกษา (id, name, major, score)
ฟังก์ชัน fetchStudentById:ใช้ setTimeout เพื่อจำลองการ ดึงข้อมูลจากฐานข้อมูล (ดีเลย์ 300ms)
ตรวจสอบว่า id เป็น string และไม่ว่าง  ถ้าไม่ใช่ส่ง errorใช้ .find() ค้นหาใน STUDENTS ว่ามี id ตรงกันไหม
ถ้าไม่เจอส่ง error | ถ้เจอข้อมูลนักศึกษากลับไป 
ทดสอบเรียกใช้งาน:ส่ง "6701"  เจอจริง  ได้ข้อมูลของ som
ส่ง "9999"  ไม่มีใน array  error "ไม่พบรหัสนักศึกษา 9999"
ส่ง 42 (number)  ไม่ใช่ string error "รหัสนักศึกษาไม่ถูกต้อง"

return new Promise(...) : คืนค่าเป็น Promise ซึ่งมีสองทางเลือกคือ 
resolve(...)  สำเร็จ ได้ข้อมูลนักศึกษา
reject(...)  ล้มเหลว ส่ง error ออกไป
ตรวจสอบ idถ้า id ไม่ใช่ string หรือเป็นค่าว่าง  ส่ง error ทันที
setTimeout(...)  
จำลองการดีเลย์ 300ms (เหมือนรอข้อมูลจากฐานข้อมูลจริง)
ค้นหาใน STUDENTS
ใช้ .find() เพื่อหานักศึกษาที่มี id ตรงกัน
ถ้าเจอ  resolve({ ...student }) คืน object นักศึกษา
ถ้าไม่เจอ  reject(new Error(...)) ส่ง error ว่าไม่พบ

การรายงานแบบ Sequential:ใช้ await ทีละตัว  ต้องรอจบก่อนถึงไปตัวถัดไป
การรายงานแบบ Parallel:ใช้ Promise.all ดึงข้อมูลพร้อมกันทุก id
Safe Report (กัน error):ใช้ try-catch-finally
ถ้าเจอ  แสดงข้อมูล
ถ้าไม่เจอหรือ id ผิด  แสดง error แต่ไม่ crash
finally จะทำงานเสมอ  แสดงข้อความปิดท้าย
main() ทดสอบทั้งหมด

EX4
1 Promise.all
ต้องการให้ ทุกงานสำเร็จครบ
ถ้ามีงานใดล้มเหลว  ทั้งหมดล้มทันที
ใช้สำหรับโหลดหน้าแรกที่ต้องมีทุกข้อมูลครบ
2 Promise.allSettled
คืนผลลัพธ์ของทุกงาน ไม่ว่าจะสำเร็จหรือผิดพลาด
ใช้สำหรับ รายงานสถานะทุกช่องทางแจ้งเตือน
3 Promise.any
คืนค่า ตัวแรกที่สำเร็จ
ถ้าทุกงานล้มเหลว  error
ใช้สำหรับ เลือก mirror server ตัวแรกที่ตอบได้
4 Promise.race
คืนค่า ตัวแรกที่เสร็จหรือพัง
ใช้สำหรับ แข่งระหว่างการดึงฐานข้อมูลกับ timeout
ถ้า timeout ชนะ  เลิกรอ
